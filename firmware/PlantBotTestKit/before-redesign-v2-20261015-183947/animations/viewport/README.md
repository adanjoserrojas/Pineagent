# Companion viewport assets

Editable Figma: https://www.figma.com/design/0HTnuMyAMeuy01nco9QaOg
Editable Rive: https://editor.rive.app/file/pineapple/2654454

The 18 SVG files are native 320 x 170 editable artwork. `companion.riv` contains all 18 continuous Rive timelines. `approval-loop.gif` is a seamless rendered preview. See `../../VIEWPORT_ANIMATIONS.md` for firmware setup and state coverage.

To view interactive Rive playback locally, serve this folder with a local HTTP server and open `preview.html`. The Rive JavaScript and WASM runtime files are included, so playback does not require a CDN.
